# 🎧 Audiobook Interativo - Salmos da Bíblia Sagrada

Este é um player de audiobook interativo desenvolvido para proporcionar uma experiência de leitura e audição fluida. O projeto foi construído utilizando **JavaScript Vanilla**, focando na manipulação de eventos de áudio e atualização dinâmica da interface (DOM).

---

👉 **[Clique aqui para ouvir o Audiobook](https://aquilesoliveira22master-hue.github.io/AudioBook-JS/)**

---

## 🚀 Funcionalidades
* **Controle Total:** Play e Pause integrados em um único botão inteligente.
* **Navegação por Capítulos:** Sistema de "Próximo" e "Anterior" que percorre os 10 capítulos (com loop automático do 10 para o 1).
* **Indicador de Progresso:** Exibição dinâmica do nome do capítulo atual na tela.
* **Design Responsivo:** Interface limpa e adaptável para desktop e dispositivos móveis.

## 📁 Estrutura do Projeto
* `index.html`: Estrutura da página e controles.
* `style.css`: Estilização e layout do player.
* `script.js`: Lógica de reprodução, troca de faixas e manipulação do DOM.
* `/Audio Book`: Pasta contendo os 10 arquivos de áudio em formato `.mp3`.
